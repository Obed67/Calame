# Contribuer à Calame

Merci de vouloir aider ! Voici comment faire.

## Lancer le projet
1. Faites un fork du dépôt, puis clonez-le
2. `npm install`
3. `npm run dev`

## Proposer une modification
1. Créez une branche : `git checkout -b ma-fonction`
2. Faites vos changements
3. Vérifiez : `npm run typecheck` puis `npm test`
4. Poussez votre branche et ouvrez une Pull Request

## Signaler un bug
Ouvrez une Issue en décrivant le problème, votre version de Windows et comment le reproduire.
